# 물류 시스템 운영가이드

> 기준 버전: 2026-10-29 · 현재 메뉴와 구현 기능 기준

## 이 문서의 사용법

이 문서는 기능 목록이 아니라 **업무를 어떤 순서로 처리하고 무엇을 확인해야 하는지**를 설명합니다.

- 처음 사용하는 담당자: `1 → 2 → 담당 업무 절차` 순서로 읽습니다.
- 재고 담당자: `3. 수불재고`, `4. 가계상재고`, `9. 엑셀 업로드할 때`를 봅니다.
- 생산·구매 담당자: `6. Workflow`, `7. MRP`를 봅니다.
- 관리자: `8. 권한과 로그`, `10. 오류가 발생했을 때`를 봅니다.
- 업로드가 실패하면 화면 메시지와 `관리자 → 접근 감사 로그`의 상세 사유를 확인합니다.

|---|---|---|---|
| 통합 검색 | 여러 업무 데이터 검색 | 검색 결과 | 전 사용자 |
| 제품 물류 | 완제품 S/N 입고·출고 | 이력 건수 | 물류 담당 |

| CART PLATFORM IEM | 구매→품질→자재→생산→출하 | Workflow별 진행 수량 | 부서 담당자 |
| MRP | BOM·생산계획 기반 소요량 | 필요·가용·부족·발주 권고 | 생산·구매 담당 |
| 기준 정보 | 품목코드·품명·Rev | 기준값 | 기준정보 관리자 |
| 관리자 | 계정·권한·업무/접근 로그 | 감사 기록 | 관리자 |

### 재고 화면별 차이

- **수불재고**, **가계상재고**, **대여재고**는 각각 별도입니다. 한쪽 수정이 다른 쪽을 자동 변경하지 않습니다.
- MRP 보유재고는 수불재고를 사용합니다. 가계상재고 숫자를 직접 사용하지 않습니다.
- Workflow 완료가 모든 재고 화면을 자동 갱신한다고 가정하지 말고 각 화면을 확인합니다.
- 제품 물류는 S/N 이력 중심이고 수불재고는 품목별 EA 수량 중심입니다.

### 화면 간 데이터 연결 기준

| 연결 | 기준 |
|---|---|
| 품목 관리 ↔ 재고 | 품목코드 |
| BOM ↔ 수불재고 | BOM 품목코드 = 수불재고 품목코드 |
| BOM ↔ 생산계획 | 제품명 |
| 자재기준정보 ↔ MRP | 품목코드 |
| Workflow 내부 단계 | Workflow 번호·품목·LOT |

품목코드는 공백을 제거해 비교하지만 대소문자, 하이픈, 밑줄 차이는 다른 코드로 처리될 수 있습니다.

## 2. 처음 사용할 때

### 로그인과 비밀번호

- 관리자가 전달한 계정으로 로그인합니다.
- 최초 로그인에서 비밀번호 변경 안내가 나오면 새 비밀번호를 설정합니다.
- 2시간 동안 작업이 없으면 세션이 만료될 수 있으므로 다시 로그인합니다.
- 메뉴나 버튼이 보이지 않으면 계정의 조회·수정·다운로드 권한을 확인합니다.

1. 관리자가 계정을 만들고 기능별 `조회 / 수정 / 다운로드` 권한을 부여합니다.
2. `기준 정보 → 품목 관리`에 표준 품목코드, 품명, Rev를 등록합니다.
3. 가계상재고와 수불재고의 기본 행을 생성합니다.
4. 실제 수량을 업로드하고 대표 품목 3개 이상을 원본과 대조합니다.
5. 원자재 LOT가 필요하면 LOT 직접 등록 또는 LOT 엑셀 업로드를 수행합니다.
6. BOM, 생산계획, 자재기준정보를 준비합니다.
7. MRP에서 대표 제품의 필요량과 보유재고를 수기로 검산합니다.
8. 관리자 로그에서 업로드가 `성공`인지 `부분 성공`인지 확인합니다.

> 중요한 일괄 작업 전에는 현재 화면의 엑셀을 다운로드해 비교본을 보관하세요.

## 3. 수불재고 운영

### 3.1 구조

수불재고는 `창고재고 / 제공재고 / 외주재고`로 나뉩니다. 창고재고는 `반제품 / 제품 / 원자재` 탭과 `A / B / F` Grade를 사용합니다.

- 재고 현황: 현재 수량 조회·수정·입출고
- 입출고 현황: 작업 이력 조회와 엑셀 다운로드
- Dashboard: 창고·분류별 현황과 기간별 이동량
- 표시 시간: 입출고 화면과 다운로드 파일 모두 한국시간(KST)

### 3.2 입고

1. 창고구분과 분류를 선택합니다.
2. 대상 행의 체크박스를 선택합니다.
3. `입고 이동`을 누릅니다.
4. 수량과 비고를 입력합니다.
5. 원자재 LOT 입고라면 LOT, 검사원, 최초 입고일자를 확인합니다.
6. 처리 후 현재 수량과 입출고 현황의 최근 이력을 대조합니다.

입고는 기존 수량에 더해집니다. 같은 품목·LOT·작업·수량을 짧은 시간 안에 반복하면 모바일에서 중복 경고가 표시될 수 있습니다.

### 3.3 출고

1. 대상 행을 선택하고 `출고 이동`을 누릅니다.
2. 출고 수량과 비고를 입력합니다.
3. 원자재 LOT 재고가 있으면 출고할 LOT를 선택합니다.
4. 총재고와 LOT 잔량이 충분한지 확인합니다.
5. 처리 후 총수량·LOT 잔량·출고 이력을 확인합니다.

등록되지 않은 LOT 또는 잔량이 부족한 LOT는 출고할 수 없습니다.

### 3.4 원자재 LOT 직접 등록

1. `창고재고 → 원자재`로 이동합니다.
2. LOT를 등록할 원자재 행 **하나만** 선택합니다.
3. `LOT 등록 → 직접 등록`을 선택합니다.
4. LOT, 분류할 수량, 최초 입고일자, 검사원, 비고를 입력합니다.
5. 수량을 입력하면 LOT 잔량과 상위 총재고가 함께 증가합니다.
6. 수량을 비우면 LOT 정보만 등록되고 총재고는 증가하지 않습니다.

`LOT 내역` 열의 숫자 버튼은 등록된 LOT 개수입니다. 누르면 LOT, 최초 입고일자, 현재 잔량을 확인할 수 있습니다.

### 3.5 원자재 LOT 엑셀 등록

1. `LOT 등록 → LOT 엑셀 업로드`를 선택합니다.
2. 예시 파일을 다운로드합니다.
3. 샘플 `RAW-001`은 실제 품목이 아니므로 실제 품목코드로 교체합니다.
4. 필수 열 `품목코드 / Grade / LOT / 수량`을 작성합니다.
5. 선택 열 `최초 입고일자`는 `YYYY-MM-DD`로 작성합니다.
6. 업로드 후 등록 건수와 입고 EA를 확인합니다.

성공 조건:

- 품목코드가 `창고재고 + 원자재 + 해당 Grade`로 존재
- Grade가 `A`, `B`, `F` 중 하나
- LOT가 비어 있지 않음
- 수량이 0 이상의 정수

실패하면 접근 감사 로그와 활동 로그에 행 번호와 원인이 남습니다.

### 3.6 일반 수불재고 엑셀 업로드

필수 열은 `품목코드 / 창고구분`, 선택 열은 `구분 / LOT / Grade / 수량 / 비고`입니다.

- 기존 `코드+창고+LOT+Grade`가 있으면 수량을 **대체**합니다.
- 신규 조합이면 행을 생성합니다.
- 수량 열이 없거나 빈 값이면 0이 될 수 있으므로 수량 파일에서는 열을 제거하지 않습니다.
- 원자재 상위 재고 행은 LOT를 비워 관리하고 원자재 LOT는 전용 기능을 사용합니다.
- 품목 관리와 가계상재고에서 품명을 찾지 못하면 해당 행은 제외됩니다.
- 제외가 있으면 접근 감사 결과가 `부분 성공`으로 기록됩니다.
- 활동 로그에는 최대 20개 제외 행과 품목코드·원인이 기록됩니다.

### 3.7 다운로드와 검산

- 제품·반제품은 화면의 재고 행을 다운로드합니다.
- 원자재 LOT가 있으면 LOT별 행과 최초 입고일자·LOT 잔량을 내보냅니다.
- LOT로 분류되지 않은 잔량은 LOT가 빈 별도 행으로 표시됩니다.
- 총재고를 검산할 때 LOT 행과 미분류 행을 함께 합산합니다.

### 3.8 대량 초기화

대량 초기화는 일반 화면 업무가 아니라 관리자·DB 작업입니다.

1. 현재 재고와 이력을 엑셀로 백업합니다.
2. Neon 스냅샷 또는 백업 테이블을 만듭니다.
3. 대상 범위가 창고재고만인지 제공·외주까지인지 승인받습니다.
4. 상위 재고와 `inventory_lot` 잔량을 함께 처리합니다.
5. 입출고 이력 삭제 여부를 별도로 승인받습니다.
6. 총합, LOT 합, 이력 건수를 검증합니다.

재고 수량 0 처리와 이력 삭제는 서로 다른 작업입니다. 운영 승인 없이 실행하지 마세요.

### 3.9 모바일·QR 재고 처리

1. 앱에서 서버에 로그인하고 현재 계정을 확인합니다.
2. `입고 / 출고 / LOT 등록` 중 작업을 먼저 선택합니다.
3. 창고 유형을 선택한 뒤 QR을 스캔하거나 품목코드·품명을 검색합니다.
4. 스캔된 품목코드, LOT, 현재 총재고와 LOT 잔량을 확인합니다.
5. 수량·검사원·최초 입고일자를 입력하고 최종 확인 후 처리합니다.
6. 최근 3분 안에 같은 품목·LOT·작업·수량이 있으면 중복 경고를 확인합니다.
7. 완료 화면과 앱 이력에서 변경 전후 수량을 대조합니다.

개발 서버 주소를 바꾸면 저장된 로그인 세션이 초기화될 수 있습니다. 운영 서버와 개발 서버를 혼동하지 마세요.

## 4. 가계상재고 운영

### 품목 관리

- `기준 정보 → 품목 관리`에서 품목코드, 품명, Rev를 등록합니다.
- 엑셀 업로드는 없는 코드만 추가하고 기존 품목을 수정하지 않습니다.
- 기존 품목 변경은 화면의 수정 기능을 사용합니다.
- 수정 후 가계상재고, 수불재고, BOM, 자재기준정보 등 연결 화면을 확인합니다.

1. 품목 관리에서 기준 품목을 준비합니다.
2. 초기 생성으로 품목·등급 행을 0으로 만듭니다.
3. 수량 업로드 또는 화면 수정으로 실제 수량을 등록합니다.
4. 입고·출고 후 이력과 Dashboard를 확인합니다.

엑셀 규칙:

- 초기 생성: `품목코드 / 구분`
- 수량 업로드: `품목코드 / 구분 / 등급 / 수량`
- 같은 품목코드+등급의 수량은 더해지지 않고 업로드 값으로 대체됩니다.
- 빈 수량은 0으로 처리될 수 있습니다.
- 입출고 화면과 다운로드 시간은 한국시간(KST)입니다.

수불재고와 자동 동기화되지 않으므로 양쪽 반영 여부를 각각 확인합니다.

## 5. 제품 물류와 대여 관리

### 제품 물류

1. 제품 분류를 선택합니다.
2. 입고 또는 출고 화면에서 S/N을 스캔하거나 엑셀을 업로드합니다.
3. 날짜, Size, 출고처를 확인합니다.
4. Dashboard에서 같은 기간과 제품 분류로 검증합니다.

권장 열은 입고 `입고일자 / Serial / Size`, 출고 `출고일자 / Serial / Size / 출고처`입니다. 같은 파일을 재업로드하면 중복될 수 있으므로 먼저 조회합니다.

- S/N 스캔, 엑셀 업로드, 선택 행 이동으로 입출고를 처리할 수 있습니다.
- 잘못 등록한 Size와 일부 항목은 화면에서 수정할 수 있습니다.
- Dashboard에서 기간·제품·Size별 입출고 건수를 확인합니다.
- 제품 물류 건수와 수불재고 EA 수량은 관리 기준이 다릅니다.

### 대여 관리

- 재고 업로드: `품목코드 / 품명 / 수량`
- 입출고 업로드: `이력ID / 구분 / 분류 / 품목코드 / 품명 / 수량 / 본부 / 부서 / 요청자 / 사이즈 / S/N / 불출일자 / 비고`
- 신규 입출고 행은 이력ID를 비웁니다.
- 기존 이력ID가 있으면 건너뜁니다.
- 출고 후 재고가 음수가 되는 작업은 거절됩니다.

## 6. CART PLATFORM IEM Workflow

전체 흐름:

`구매 입고 → 수입 검사 의뢰 → 품질 승인/검사 → 자재 확인 → 생산 요청/승인 → 생산 완료 → 자재 확인 → 공정 검사 → 포장 요청/완료 → 최종 자재 확인 → 출하`

| 담당 | 해야 할 일 | 완료 전 확인 |
|---|---|---|
| 구매 | 입고 등록, 검사 의뢰 | Product·코드·품명·LOT·수량·입고일 |
| 품질 | 승인/반려, 수입·공정 검사 | 의뢰 수량, 결과, 첨부파일 |
| 자재 | 단계 확인, 다음 단계 요청, 출하 | 실물 수량, LOT, 잔량·불량 |
| 생산 | 생산 승인, 생산·포장 완료 | 구성품, 양품·불량, 새 LOT |

구매 엑셀 필수 열은 `Product / 품목코드 / 품명 / LOT / 입고 수량 / 입고 일자`입니다. 각 행은 새 Workflow를 만들므로 재업로드 전에 기존 건을 확인합니다.

반려, 불량 이관, 잔량 재입고·재사용은 전용 기능을 사용하고 원본 Workflow를 삭제하지 않습니다.

- Dashboard에서 부서별 대기·진행·완료 건을 확인합니다.
- 검사 첨부파일은 해당 검사 건에서 등록·다운로드·삭제합니다.
- 생산 중 발생한 불량과 입고 원자재 불량을 구분합니다.
- 생산·포장 완료 전 양품, 불량, 구성품, 새 LOT를 확인합니다.

## 7. MRP 운영

### 준비 순서

1. BOM 전체본을 검토하고 업로드합니다.
2. 생산계획 전용 양식에 날짜별 계획을 입력합니다.
3. 수불재고의 품목코드와 실제 수량을 확인합니다.
4. 자재기준정보의 업체, LT(주), MOQ를 입력합니다.
5. MRP Result에서 기간과 제품을 선택합니다.
6. 대표 품목을 수기로 검산합니다.

### BOM

권장 열: `제품명 / 품목코드 / 품목명 / 소요량`

**BOM 업로드는 기존 BOM 전체를 교체합니다.** 반드시 전체본을 백업하고 업로드합니다.

### 생산계획

- 화면에서 월을 선택해 전용 양식을 받습니다.
- 6번째 행 헤더 구조를 유지합니다.
- `사이즈` 열 값은 BOM 제품명과 연결되는 생산계획 제품명입니다.
- 1 이상의 정수만 추가·수정됩니다.
- 0 또는 빈칸으로 기존 계획이 자동 삭제되지는 않습니다.

### 재고 포함 기준

| 수불재고 | MRP 포함 |
|---|---|
| 창고재고 | A등급만 |
| 제공재고 | 등급 제한 없이 |
| 외주재고 | 등급 제한 없이 |

계산 개념:

1. 필요량 = 생산계획 × BOM 소요량
2. 가용재고 = 포함 대상 수불재고 − 선택 기간 이전 계획 소요량
3. 부족량 = 필요량 − 가용재고, 최소 0
4. 권장 발주량 = 부족량을 MOQ 배수로 올림

MRP 결과는 권고이며 실제 발주나 재고 차감은 자동 실행하지 않습니다.

각 메뉴에서 하는 일:

- BOM: 제품별 구성품과 1대당 소요량 관리
- 생산 계획: 월별 일자별 수량 입력과 주별 합계 확인
- 자재 기준 정보: 공급업체, LT(주), MOQ, 비고 관리
- MRP Result: 필요량, 가용재고, 부족량, 권장 발주량 조회·다운로드
- Dashboard: 전체 부족 품목과 주요 지표 확인

## 8. 권한과 로그

### 계정 관리

- 관리자는 계정을 만들고 역할과 팀을 지정합니다.
- 기능별 조회·수정·다운로드 권한을 설정합니다.
- 비밀번호를 잊은 사용자는 관리자가 초기화할 수 있습니다.
- 계정 삭제 전 해당 사용자의 업무 이력과 인수인계를 확인합니다.

기능별로 `조회 / 수정 / 다운로드`를 분리합니다. 버튼이 없거나 업로드가 거절되면 해당 기능의 `수정` 권한을 확인합니다.

| 로그 | 확인 목적 | 예시 |
|---|---|---|
| 활동 로그 | 실제 업무 변경 | 재고 업로드, 입고, 삭제, 권한 변경 |
| 접근 감사 로그 | 요청 결과와 접속 정보 | URL, 상태코드, IP, 브라우저, 실패 상세 |

접근 감사 결과:

- `성공`: 요청 정상 처리
- `부분 성공`: 일부 행 반영, 일부 행 제외
- `실패`: 파일·컬럼·값·대상 데이터 검증 실패
- `인증필요 / 세션만료 / 권한없음`: 계정 또는 세션 문제

`200 OK`는 요청 처리 성공일 뿐 데이터의 업무적 정확성을 보장하지 않습니다.

### 품목 기준정보 변경 영향

- 품목 관리의 화면 수정은 연결된 가계상재고, 가계상 이력, BOM, 수불재고, 자재기준정보 등에 코드·품명·Rev 변경을 전달합니다.
- 품목 관리 엑셀 업로드는 없는 코드만 추가하고 기존 코드를 갱신하지 않습니다.
- Workflow의 구성품 설정은 MRP BOM과 별도일 수 있으므로 기준정보 변경 후 부서별 화면을 확인합니다.

### 백업

관리자 DB 백업 기능은 현재 데이터 파일을 내려받는 기능입니다. Neon 운영 DB의 복구 시점이 필요한 작업은 Neon 스냅샷과 별도 백업 절차를 사용합니다.

## 9. 엑셀 업로드할 때

### 업로드 전

1. 해당 화면에서 최신 양식을 다운로드합니다.
2. 파일명에 업무명과 기준일을 넣습니다.
3. 열 제목, 데이터 시작 행, 날짜 형식을 유지합니다.
4. 품목코드 앞자리 0 보존을 위해 텍스트 형식을 사용합니다.
5. `추가 / 대체 / 전체 교체` 중 어떤 동작인지 확인합니다.
6. 원본과 현재 시스템 데이터를 백업합니다.

### 업로드 후

1. 성공·부분 성공·실패 상태를 확인합니다.
2. 신규·수정·제외 합계가 입력 행 수와 맞는지 확인합니다.
3. 제외 사유의 행 번호와 품목코드를 원본에서 찾습니다.
4. 대표 품목 3개 이상의 수량·등급·LOT를 대조합니다.
5. 이력과 활동/접근 로그를 확인합니다.

| 업로드 | 저장 방식 |
|---|---|
| 품목 관리 | 없는 코드만 추가, 기존 코드 제외 |
| 가계상 초기 생성 | 없는 품목·등급 행을 0으로 생성 |
| 가계상 수량 | 품목+등급 수량 대체 |
| 수불 초기 생성 | 없는 창고·품목 조합 생성 |
| 수불 수량 | 코드+창고+LOT+Grade 수량 대체/생성 |
| 원자재 LOT | LOT 잔량과 총재고에 입고 수량 추가 |
| BOM | 기존 BOM 전체 교체 |
| 생산계획 | 제품+날짜 추가/수정 |
| 자재기준정보 | 품목코드별 추가/갱신 |
| 대여재고 | 분류+품목 수량 대체/생성 |
| Workflow 구매 | 행마다 신규 Workflow 생성 |

## 10. 오류가 발생했을 때

### 업로드가 400으로 실패

1. 화면 오류 메시지를 확인합니다.
2. `관리자 → 접근 감사 로그`에서 해당 URL의 상세 사유를 확인합니다.
3. 필수 컬럼, 행 번호, Grade, 수량, 날짜를 수정합니다.
4. LOT 업로드라면 실제 원자재 품목코드+Grade가 존재하는지 확인합니다.

### 수불재고 업로드가 부분 성공

- 활동 로그의 제외 사유에서 행 번호와 품목코드를 확인합니다.
- 품목 관리와 가계상재고에서 품명을 찾지 못한 품목은 제외됩니다.
- 기준정보를 먼저 등록하고 같은 파일을 재업로드합니다.

### 재고가 있는데 MRP에서 0

1. BOM 코드와 수불재고 코드가 같은지 확인합니다.
2. 생산계획 제품명과 BOM 제품명이 같은지 확인합니다.
3. 창고재고가 A등급인지 확인합니다.
4. 재고가 가계상 또는 대여재고에만 있는지 확인합니다.
5. 선택 기간 이전 계획이 차감됐는지 확인합니다.

### 시간이 9시간 차이 남

수불·가계상 이력은 UTC 저장값을 KST로 변환합니다. 최신 배포 여부를 확인하고 화면과 다운로드 파일을 비교합니다.

### 숫자가 맞지 않음

- 창고구분·분류·Grade·기간 필터를 확인합니다.
- 원자재는 총재고 = LOT별 잔량 합 + 미분류 잔량인지 확인합니다.
- 다운로드에서 LOT 행과 미분류 행을 함께 합산합니다.
- 활동 로그로 마지막 작업자를 확인합니다.

## 11. 통합 검색과 화면 도우미

### 통합 검색

- 품목코드, 품명, S/N, LOT 등 알고 있는 값을 입력합니다.
- 검색 결과가 어느 메뉴의 데이터인지 확인한 뒤 원본 화면으로 이동합니다.
- 재고 수량과 입출고 이력은 해당 재고 화면에서 다시 확인합니다.

### 화면 도우미

- 우측 하단 도우미에서 재고, 입출고, MRP 관련 질문을 입력할 수 있습니다.
- 답변의 이동 버튼으로 관련 메뉴를 열 수 있습니다.
- 도우미는 조회를 돕는 기능이며 입력·수정·삭제를 대신하지 않습니다.
- 답변이 화면과 다르면 실제 업무 화면과 활동 로그를 기준으로 판단합니다.
