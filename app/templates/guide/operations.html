02

처음 사용할 때

기준정보와 재고를 처음 등록할 때 아래 순서대로 진행합니다.

로그인과 비밀번호

  • 관리자가 전달한 계정으로 로그인합니다.
  • 최초 로그인에서 비밀번호 변경 안내가 나오면 새 비밀번호를 설정합니다.
  • 2시간 동안 작업이 없으면 세션이 만료될 수 있으므로 다시 로그인합니다.
  • 메뉴나 버튼이 보이지 않으면 계정의 조회·수정·다운로드 권한을 관리자에게 확인합니다.
계정 생성 후 기능별 조회·수정·다운로드 권한을 부여합니다.
품목 관리에 표준 품목코드, 품명, Rev를 등록합니다.
가계상·수불재고 기본 행을 만들고 실제 수량을 업로드합니다.
원자재 LOT, BOM, 생산계획, 자재기준정보를 준비합니다.
대표 품목을 수기로 검산하고 성공·부분 성공 로그를 확인합니다.
중요한 일괄 작업 전에는 현재 화면의 엑셀을 내려받아 작업 전 비교본을 보관하세요.
03

수불재고 사용 방법

입출고, 원자재 LOT 등록, 엑셀 업로드 방법을 설명합니다.

입고·출고 표준 절차

입고

창고·분류 선택 → 행 선택 → 입고 이동 → 수량·비고 입력 → 재고와 최근 이력 대조

출고

행 선택 → 출고 이동 → 수량 입력 → 원자재 LOT 선택 → 총재고·LOT 잔량·이력 확인

등록되지 않은 LOT 또는 잔량이 부족한 LOT는 출고할 수 없습니다. 총재고만 임의로 차감하지 마세요.

원자재 LOT 직접 등록

창고재고 → 원자재에서 대상 행 하나만 선택합니다.
LOT 등록 → 직접 등록을 선택합니다.
LOT, 수량, 최초 입고일자, 검사원, 비고를 입력합니다.
수량 입력 시 LOT 잔량과 총재고가 함께 증가합니다. 수량을 비우면 정보만 등록됩니다.

LOT 내역의 숫자 버튼은 등록된 LOT 개수입니다. 누르면 LOT·최초 입고일자·현재 잔량을 확인합니다.

원자재 LOT 엑셀 등록

필수 열허용 값실패 조건
품목코드창고재고 원자재에 존재하는 코드코드+Grade 대상 없음
GradeA / B / F그 외 값 또는 빈칸
LOT실제 LOT빈칸
수량0 이상의 정수음수·소수·문자
최초 입고일자YYYY-MM-DD, 선택날짜 형식 오류
예시 파일의 RAW-001은 샘플입니다. 그대로 올리지 말고 실제 품목코드로 교체하세요.

일반 수불재고 업로드

  • 필수 열: 품목코드 / 창고구분
  • 선택 열: 구분 / LOT / Grade / 수량 / 비고
  • 기존 코드+창고+LOT+Grade는 수량이 대체되고 신규 조합은 생성됩니다.
  • 품명을 찾지 못한 행은 제외되며 결과가 부분 성공으로 기록됩니다.
  • 활동 로그 상세에 최대 20개 제외 행·품목코드·원인이 남습니다.

다운로드 검산

원자재는 LOT별 행과 미분류 잔량 행으로 내려갑니다. 화면 총재고와 비교할 때 LOT 행과 LOT가 빈 미분류 행을 함께 합산합니다.

선택 행 대량 수정

기능사용 조건처리 후 확인
수량 일괄 수정같은 화면에서 수정할 행을 선택하고 각 행의 새 수량 입력총재고·LOT 잔량·입출고 이력 대조
LOT 일괄 수정선택한 재고 행의 LOT 값을 같은 값으로 변경할 때기존 LOT 이력과 신규 LOT 조회
비고 일괄 수정선택 행에 공통 관리 메모를 남길 때필터 해제 후 전체 대상 확인
선택 삭제실제 삭제 대상만 선택하고 수정 권한 보유대상 건수·연결 LOT·이력 확인
필터가 적용된 상태에서도 체크된 행만 처리됩니다. 실행 전 선택 건수와 첫 행·마지막 행의 품목코드를 확인하세요.

이력과 Dashboard

  • 입출고 이력은 유형, 품목코드·품명·LOT·작업자, 품목 구분으로 검색합니다.
  • 화면 수량이 예상과 다르면 최근 이력의 변경 전·후 수량과 작업자를 먼저 확인합니다.
  • Dashboard의 합계는 현재 필터와 기간을 확인한 뒤 다운로드 결과와 비교합니다.

모바일·QR 재고 처리

로그인 후 현재 계정을 확인하고 입고·출고·LOT 등록 중 작업을 선택합니다.
창고 유형을 선택하고 QR을 스캔하거나 품목코드·품명을 검색합니다.
품목코드·LOT·총재고·LOT 잔량을 확인한 뒤 수량과 검사 정보를 입력합니다.
최근 3분 내 동일 작업 경고가 나오면 실제 연속 작업인지 확인합니다.
완료 화면과 앱 이력에서 변경 전후 수량을 대조합니다.
04

가계상재고 운영

수불재고와 독립된 품목·등급별 재고입니다.

품목 관리

  • 기준 정보 → 품목 관리에서 품목코드, 품명, Rev를 등록합니다.
  • 신규 품목은 직접 등록하거나 엑셀로 추가합니다.
  • 엑셀 업로드는 없는 코드만 추가하며 기존 품목을 수정하지 않습니다.
  • 기존 품목의 코드·품명·Rev 변경은 화면의 수정 기능을 사용합니다.
  • 화면 수정 후 가계상재고, 수불재고, BOM, 자재기준정보 등 연결된 화면을 확인합니다.
품목 관리에서 기준 품목을 준비합니다.
초기 생성으로 품목·등급 행을 0으로 만듭니다.
품목코드 / 구분 / 등급 / 수량 파일로 실제 수량을 등록합니다.
입출고 후 이력과 Dashboard를 확인합니다.
수량 업로드는 기존 수량에 더하지 않고 업로드 값으로 대체합니다. 빈 수량은 0이 될 수 있습니다.

수불·가계상 입출고 화면과 이력 다운로드 시간은 한국시간(KST)으로 표시됩니다.

등급·수량 변경

  • 단일 행의 수량과 Grade는 해당 행의 수정 기능을 사용합니다.
  • 여러 행을 같은 Grade 또는 수량으로 바꿀 때만 일괄 수정 기능을 사용합니다.
  • Grade 변경 전 동일 품목·동일 Grade 행이 이미 있는지 확인해 중복 기준을 피합니다.
  • 품목 기준정보 수정 후에는 품목 관리 이력과 연결된 가계상재고 행을 함께 확인합니다.
05

제품 물류와 대여 관리

S/N 이력과 대여용 재고는 일반 수불재고와 별도로 운영합니다.

제품 물류

제품 분류 → 입고/출고 → 스캔 또는 엑셀 → 날짜·Size·출고처 확인 → Dashboard 검증

대여 관리

분류·품목 재고 준비 → 요청자·조직·S/N 포함 출고/입고 → 이력 확인

제품 입고·출고

  • 제품 분류를 먼저 선택한 뒤 입고 또는 출고 화면으로 이동합니다.
  • S/N 스캔, 엑셀 업로드, 선택 행 이동으로 입출고를 처리할 수 있습니다.
  • 잘못 등록한 Size와 일부 항목은 화면에서 수정할 수 있으며 삭제 작업은 권한과 대상 범위를 확인합니다.
  • Dashboard에서 기간·제품·Size별 입출고 건수를 확인합니다.
  • 제품 물류의 건수와 수불재고의 EA 수량은 관리 기준이 다릅니다.
작업입력·선택 기준중복 방지 확인
S/N 입고제품 분류, 입고일자, Serial, Size통합검색으로 동일 Serial 기존 이력 확인
S/N 출고출고 대상 선택, 출고일자, Size, 출고처현재 재고 상태와 마지막 입고 이력 확인
입출고 이동선택한 행을 반대 상태로 이동선택 건수와 이동 후 목록 확인
대량 수정허용 필드와 동일 변경값 입력필터 범위·대상 Serial·변경 로그 확인

대여 재고와 이력

  • 분류를 만든 뒤 품목을 직접 등록하거나 엑셀로 업로드합니다.
  • 출고 시 본부, 부서, 요청자, 사이즈, S/N, 비고를 확인합니다.
  • 입고는 기존 출고 이력을 기준으로 반납 처리합니다.
  • 재고 현황과 입출고 이력은 각각 엑셀로 다운로드할 수 있습니다.
대여 분류와 품목별 보유 수량을 준비합니다.
출고할 품목과 수량을 선택하고 요청자·조직·S/N을 입력합니다.
출고 완료 후 재고 감소와 대여 이력 생성을 확인합니다.
반납 시 기존 출고 이력을 찾아 입고 처리합니다.
재고 회복과 반납일·처리자 기록을 확인합니다.
대여 이력 엑셀 수정 시 기존 행의 이력ID를 유지합니다. 신규 행만 이력ID를 비워야 기존 기록이 중복 생성되지 않습니다.

권장 엑셀 열

  • 제품 입고: 입고일자 / Serial / Size
  • 제품 출고: 출고일자 / Serial / Size / 출고처
  • 대여 재고: 품목코드 / 품명 / 수량
  • 대여 이력: 전용 13개 열을 유지하고 신규 행의 이력ID는 비웁니다.
같은 제품 물류 파일을 다시 올리면 중복 이력이 생길 수 있습니다. 재업로드 전 기존 S/N을 조회하세요.
06

CART PLATFORM IEM 업무 처리

구매 입고부터 검사, 생산, 포장, 출하까지 Workflow 번호와 수량 이력으로 관리합니다.

Dashboard에서 부서별 대기·진행·완료 건을 먼저 확인하고, 각 담당 메뉴에서 본인 단계의 작업을 처리합니다. 부분 수량은 하나의 Workflow에 섞지 않고 새 Workflow로 분리합니다.

기본 진행 순서

구매 입고›수입검사 의뢰›수입검사›자재 확인›생산›공정검사›세트 포장›최종 확인›제품 출고
CRADLE 전용 경로 CRADLE은 완성된 포장 구성품으로 처리하므로 수입검사 후 생산·공정검사를 생략하고 세트 포장 대기로 이동합니다. RING은 생산과 공정검사를 진행합니다.
담당주요 작업완료 전 확인
구매입고 등록·수정·삭제·수입검사 의뢰Product·코드·품명·LOT·입고수량·입고일
품질의뢰 승인/반려·수입검사·공정검사의뢰 수량·양품/불량·A/B/F·첨부자료
자재결과 확인·다음 단계 요청·불량 이관 승인·출고실물 수량·LOT·잔량·불량·검사 결과
생산생산 승인·생산 완료·RING/CRADLE 세트 포장구성품·양품·작업 불량·자재 반납 불량·새 LOT

부분 수량 처리

현재 상황진행 수량남은 수량 처리
입고 10개 중 5개만 수입검사 의뢰기존 Workflow 5개가 품질로 이동5개를 새 구매 Workflow로 자동 분리

RING·CRADLE 세트 생산과 포장

RING 생산

구성 원자재를 생산 완료하면 RING 코드와 새 LOT로 변환합니다. 이후 공정검사에서 A/B/F 등급을 판정합니다.

제품 포장

RING과 CRADLE을 1:1로 결합해 CART PLATFORM IEM을 만듭니다. 적은 쪽 수량만큼 포장할 수 있습니다.

예: RING 2개와 CRADLE 4개가 있으면 IEM 2세트를 포장하고, 남은 CRADLE 2개는 세트 미사용 잔량으로 보관합니다.

  • 품질 반려로 구매 단계에 돌아왔고 활성 요청과 검사 결과가 없으면 수량을 다시 수정할 수 있습니다.
  • 삭제는 수입검사 의뢰 전 또는 모든 요청이 반려된 구매 단계에서만 가능합니다.
  • 삭제 처리한 건의 Workflow 번호와 작업 이력은 재사용하지 않습니다.
  • Workflow 번호는 한국시간 날짜별 순번으로 생성합니다.

  • 검사 첨부파일은 해당 검사 건에서 등록·다운로드·삭제합니다.
  • 부분 처리 후 원본과 분리 Workflow의 수량 합계가 기존 수량과 같은지 확인합니다.
  • 생산·포장 완료 전 양품, 불량, 사용 구성품, 새 LOT를 확인합니다.
  • 출고 전 포장 수량, LOT, 남은 출고 대기 수량을 최종 확인합니다.
  • 잘못 등록한 구매 건은 구매 화면의 삭제 기능을 사용합니다.

권한과 작업 기록 확인

사용자별 권한과 실제 작업 내역을 확인하는 방법입니다.

계정 관리

  • 관리자는 계정을 만들고 역할과 팀을 지정합니다.
  • 기능별 조회·수정·다운로드 권한을 따로 설정합니다.
  • 비밀번호를 잊은 사용자는 관리자가 초기화할 수 있습니다.
  • 계정 삭제 전 해당 사용자의 업무 이력과 인수인계를 확인합니다.
활동 로그

입고, 업로드, 수정, 삭제, 권한 변경 등 실제 업무 변경 내용을 확인합니다.

접근 감사 로그

URL, 상태코드, IP, 브라우저, 실패·부분 성공의 상세 사유를 확인합니다.

결과의미조치

권한은 기능별 조회 / 수정 / 다운로드로 나뉩니다. 작업 완료 후에는 화면의 대상 건수와 실제 데이터를 함께 확인합니다.

권한 적용 기준

  • 조회 권한이 없으면 메뉴와 화면에 접근할 수 없습니다.
  • 수정 권한을 선택하면 해당 기능의 조회 권한도 함께 필요합니다.
  • 다운로드 권한은 화면 조회와 별도로 파일 반출 범위를 제어합니다.
  • 관리자는 전체 기능 권한을 가지며 일반 사용자는 담당 업무에 필요한 최소 범위만 부여합니다.
  • 권한 변경 후 대상 사용자가 다시 로그인해 메뉴와 버튼 노출을 확인합니다.

접근 감사 로그에서 상태코드와 요청 결과를 확인합니다.
데이터가 변경된 작업이면 활동 로그에서 대상과 변경 내용을 확인합니다.
엑셀 작업이면 처리 건수와 제외 행 사유를 원본 파일과 대조합니다.

품목 기준정보 변경 영향

  • 화면에서 품목을 수정하면 연결된 가계상재고, 이력, BOM, 수불재고, 자재기준정보 등에 변경을 전달합니다.
  • 품목 관리 엑셀 업로드는 없는 코드만 추가하고 기존 코드를 갱신하지 않습니다.
  • Workflow 구성품 설정은 MRP BOM과 별도일 수 있으므로 관련 부서 화면을 함께 확인합니다.

엑셀 업로드할 때

업로드 전 준비사항과 업로드 후 확인할 내용을 정리했습니다.

업로드 전 확인

해당 화면에서 받은 최신 양식을 사용하고 열 제목과 시작 행을 유지합니다. 품목코드, 날짜, Grade, LOT를 확인하고 해당 업로드가 추가·수량 대체·전체 교체 중 어느 방식인지 먼저 확인합니다.

업로드 후 확인

처리 결과의 신규·수정·제외 건수를 확인합니다. 제외된 행은 로그에서 원인을 확인하고, 대표 품목의 화면 수량과 이력이 실제 파일 내용과 일치하는지 대조합니다.

저장 방식

업로드동작
품목 관리없는 코드만 추가
가계상 수량품목+등급 수량 대체
수불 수량코드+창고+LOT+Grade 대체/생성
원자재 LOTLOT 잔량과 총재고에 입고 수량 추가
BOM기존 BOM 전체 교체
생산계획제품+날짜 추가/수정
Workflow 구매행마다 신규 Workflow 생성

업로드 공통 절차

작업할 화면에서 최신 예시 파일 또는 양식을 내려받습니다.
열 제목을 바꾸지 않고 필수값·숫자·날짜 형식을 확인합니다.
대표 1~3행으로 먼저 업로드해 저장 방식을 확인합니다.
전체 파일을 업로드하고 신규·수정·제외 건수를 기록합니다.
대표 품목을 화면·이력·다운로드 파일에서 다시 검산합니다.
같은 파일을 다시 업로드하기 전에 저장 방식이 추가인지 대체인지 확인하세요. S/N 입출고, LOT 입고, Workflow 구매 등록은 재업로드 시 중복 이력이 생길 수 있습니다.

형식 점검

  • 품목코드와 LOT의 앞뒤 공백, 숫자형 셀의 소수점, 날짜 셀의 표시 형식을 확인합니다.
  • Grade는 화면에서 허용하는 값만 사용하고 수량은 음수·문자·빈칸 허용 여부를 확인합니다.
  • 오류가 난 행만 수정해 다시 올릴 때 이미 성공한 행이 중복 반영되지 않는지 확인합니다.

오류가 발생했을 때

화면 메시지, 작업 기록, 업로드한 원본 파일을 차례로 확인합니다.

엑셀 업로드 실패

  1. 화면 오류 메시지를 확인합니다.
  2. 작업 기록에서 실패한 작업의 상세 사유를 확인합니다.
  3. 표시된 행 번호의 필수 컬럼, Grade, 수량, 날짜를 수정합니다.
  4. LOT 업로드는 실제 원자재 코드+Grade 존재 여부를 확인합니다.

부분 성공

활동 로그의 제외 사유에서 행 번호와 품목코드를 확인합니다. 품목 관리와 가계상재고에서 품명을 찾지 못한 품목은 기준정보 등록 후 재업로드합니다.

MRP 재고 0

  • BOM 코드와 수불재고 코드가 같은가?
  • 생산계획 제품명과 BOM 제품명이 같은가?
  • 창고재고가 A등급인가?
  • 재고가 가계상 또는 대여재고에만 있는가?
  • 선택 기간 이전 계획이 차감됐는가?

수량 불일치

  • 창고·분류·Grade·기간 필터를 확인합니다.
  • 원자재 총재고 = LOT 잔량 합 + 미분류 잔량인지 확인합니다.
  • 다운로드에서 LOT 행과 미분류 행을 함께 합산합니다.
  • 활동 로그로 마지막 작업자를 확인합니다.

Workflow가 예상 단계와 다를 때

  • Dashboard와 각 부서 화면에서 현재 단계와 담당 부서를 확인합니다.
  • 요청이 반려됐는지, 실물 불일치로 보류됐는지, 검사 결과 오류로 재검사 중인지 구분합니다.
  • 부분 수량은 원본과 분리 Workflow 번호를 함께 검색해 합계 수량을 확인합니다.
  • CANCELLED 또는 MERGED 상태면 원본 번호의 이력과 대표 Workflow를 확인합니다.
  • 잔량 창고에서는 사유가 부분 요청, 부분 출고, 세트 미사용, 불량 중 무엇인지 먼저 확인합니다.
